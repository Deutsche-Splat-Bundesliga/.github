## Wer wir sind

Die **Deutsche Splat Bundesliga (DSB) e.V.** ist der zentrale Anlaufpunkt für die deutschsprachige, kompetitive Splatoon-Community. Wir organisieren Turniere, Ligen und Community-Events rund um die Splatoon-Reihe und bieten allen Spieler:innen — vom Einsteiger bis zum Top-Team — eine Heimat.

This GitHub organization hosts the open-source tools we build to run our Discord server, tournaments, and broadcasts.

## 🛠️ Our Projects

| Repository | Description |
|---|---|
| [**Sunny**](https://github.com/Deutsche-Splat-Bundesliga/Sunny) | The Discord bot powering our official server — tournament management via Challonge, Twitch/YouTube notifications, and community utilities. |
| [**Streaming-Tool**](https://github.com/Deutsche-Splat-Bundesliga/Streaming-Tool) | Our in-house tool for producing tournament broadcasts and stream overlays. |
